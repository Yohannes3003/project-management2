# Project Management API

Backend REST API untuk sistem Project Management menggunakan Golang, PostgreSQL, JWT Authentication, dan GORM.

## Tech Stack

- Golang
- PostgreSQL
- JWT Authentication
- GORM

## Fitur

- Authentication Login & Register
- JWT Authorization
- CRUD User
- CRUD Project
- CRUD Task
- Refresh Token
- Pagination
- Search & Filter
